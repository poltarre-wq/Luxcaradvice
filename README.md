# LuxCarAdvice Website

Official web application for **LuxCarAdvice.com** — an independent automotive and fleet advisory service.

## Features
- **Interactive Car Finder:** Helps clients identify vehicle segments based on needs and powertrain preferences.
- **TCO & Pricing Analytics:** Evaluates Total Cost of Ownership across Mid-Range, Premium, and Luxury vehicles.
- **Lead Capture:** Collects tailored consultation requests.
